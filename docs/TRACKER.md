# Modern look: tracker

The one place that says, at any moment, what is **missing**, **implemented** (built, not yet
proven) and **tested** (proven by a named check). Every role updates it after each step;
nothing counts as done until it is *tested* with the evidence filled in.

Status: `missing` → `in progress` → `implemented` → `tested` (or `broken` if a check fails).
Evidence: the check that proves it (a `tools/qa` check, a regression, renders looked at,
with the frames) and the commit.
